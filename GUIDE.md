# Руководство пользователя VideoStat

Система автоматически превращает горизонтальное донорское видео (YouTube, TikTok, Instagram) в вертикальное видео 9:16 для TikTok/Reels: аватар озвучивает ту же речь, B-roll подставляется как фон.

---

## Доступ к боту

Бот закрытый — отвечает только разрешённым пользователям.

Чтобы добавить нового пользователя, открой `.env` и добавь его Telegram username (без `@`) в переменную:

```
TELEGRAM_ALLOWED_USERNAMES=gregoryKarman,otherUser
```

После изменения перезапустить API сервер (`make run`).

---

## Запуск сервисов

Перед работой должны быть запущены все четыре сервиса:

```bash
make up                  # инфраструктура (postgres, rabbitmq, minio)
make run                 # API + Telegram бот
make run_worker_core     # обработка событий
make run_worker_cron     # polling каждую минуту
make run_worker_notify   # Telegram уведомления
```

## Команды бота

### `/start`

Открывает главное меню с кнопками быстрого доступа:
- **Добавить ссылку на блогера**
- **Экспорт видео в Excel**
- **Анализ видео по ссылке**

---

### Создать блогера (`/create_blogger`)

Добавляет канал блогера — система будет отслеживать его видео и каждую ночь в 03:00 обновлять список.

**Шаги:**
1. Нажать кнопку **Создать блогера** или написать `/create_blogger`
2. Выбрать платформу: YouTube / TikTok / Instagram
3. Отправить ссылку на канал блогера

```
Пример:
https://www.youtube.com/@MrBeast
https://www.tiktok.com/@khaby.lame
```

После создания бот ответит ID блогера.

---

### Экспорт видео (`/export_videos`)

Отправляет Excel-файл `videos.xlsx` с тремя листами: YouTube, TikTok, Instagram. Удобно для анализа и отбора доноров.

---

### Запустить генерацию (`/start_process_video`)

Главная функция — запускает полный пайплайн генерации вертикального видео.

**Шаги:**
1. Написать `/start_process_video` или нажать соответствующую кнопку
2. Отправить ссылку на донорское видео

```
Пример:
https://www.youtube.com/watch?v=dQw4w9WgXcQ
https://www.tiktok.com/@user/video/123456789
```

3. Бот подтвердит запуск:
   ```
   ✅ Генерация запущена
   ```

4. Дождаться уведомлений (см. ниже)

**Если видео уже обрабатывалось** — бот предложит выбор:
- **Да** — сбросить все данные и запустить заново
- **Нет** — отменить

## Уведомления о готовности

Бот присылает два уведомления по мере продвижения пайплайна:

**1. Аватар готов** (через 5–15 минут после запуска):
```
✅ Видео готово
ID: 928a54c4-...
S3: https://…/avatar.mp4
```

**2. Итоговое видео готово** (ещё через 5–15 минут, после сборки Shotstack):
```
🎬 Итоговое видео готово
Исходник: https://youtube.com/watch?v=...
Смотреть: https://cdn.shotstack.io/…/output.mp4
```

Ссылка **Смотреть** — это финальное вертикальное 9:16 видео, готовое к публикации.

## Сколько ждать

| Этап | Время |
|------|-------|
| Анализ транскрипта (AssemblyAI) | 1–3 мин |
| Генерация аватара (HeyGen) | 5–15 мин |
| Генерация B-roll клипов (Kling) | 3–10 мин |
| Сборка финального видео (Shotstack) | 5–15 мин |
| **Итого** | **15–45 мин** |

## Возможные проблемы

### Бот не отвечает
- Убедись что username добавлен в `TELEGRAM_ALLOWED_USERNAMES`
- Проверь что сервис `make run` запущен

### Генерация зависла — нет уведомления больше часа
- Проверь логи `make run_worker_cron` — там будут сообщения об ошибках
- Частая причина: закончился баланс на Kling (`Account balance not enough`) — пополнить счёт на [kling.ai](https://kling.ai)
- После пополнения крон автоматически подхватит зависшие сегменты в следующую минуту

### Ошибка при отправке ссылки
- Убедись что видео публичное
- Поддерживаются: YouTube, TikTok, Instagram

### Аватар говорит не то
- Проверь ключи HeyGen (`HEYGEN_AVATAR_ID`, `HEYGEN_VOICE_ID`) в `.env`

## Полный пайплайн (для понимания)

```
/start_process_video <url>
        │
        ▼
[1] AssemblyAI транскрибирует видео
        │ words с ms-таймингами
        ▼
[2a] HeyGen генерирует аватар    [2b] Kling генерирует B-roll клипы
     (SSML с паузами оригинала)       (OpenAI пишет промпты,
     1280×720, горизонтальное          Kling рендерит 9:16)
        │                                       │
        └──────────── оба готовы ───────────────┘
                            │
                            ▼
                [3] Shotstack собирает 720×1280
                    B-roll — фон (весь экран)
                    Аватар — внизу экрана
                            │
                            ▼
                [4] Уведомление в Telegram
```
